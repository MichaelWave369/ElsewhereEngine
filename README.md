# Elsewhere Engine

*The universe broke into stories. The stories forgot they were one.*

Original interconnected science-fantasy setting and browser-playable experimental fiction from Φ369 Labs.

The first development work will be proposed through pull requests. The cosmology supports optional connections to other Φ369 Labs projects without rewriting their existing canon or revealing late-game secrets.
