# Opt-in canon bridge contract (draft 0.1)

Other Φ369 Labs worlds retain full creative and technical autonomy. Elsewhere Engine catalogs possible bridges, never silently claims them.

A bridge proposal must record:

- **Source / target**: exact repository and link to target's public, spoiler-safe canon.
- **Visibility**: optional cameo, side quest, artifact reference, or shared mechanics.
- **Version**: an explicit schema revision with backward compatibility.
- **Player consent**: whether it opens external sites or exchanges any save data.
- **Facts vs. speculation**: separate confirmed canonical overlap from in-world rumor.
- **Spoiler fence**: no major revelations from existing stories in public documentation.
- **Test contract**: links launch successfully when possible; unavailable content gives a graceful fallback.

**First candidate:** a non-spoiler artifact or broadcast in *Race to Oblivion*, but **not implemented**. The Interval / Elsewhen / ARCLight remain governed by that game's canon. No dependency is added to either game as part of this PR.
