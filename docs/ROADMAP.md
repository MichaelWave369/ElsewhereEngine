# Development roadmap: small doors into a large universe

## Rung 0: World charter and playable proof (this PR)
- [x] Original public cosmology, twelve provisional realms and magic constraints.
- [x] Browser-playable Crossroads reception hall with five inspectable objects.
- [x] Three independent evidence records and a gated Elevator 13 decision.
- [x] Two distinct persistent endings, journal, local-only save and reset.
- [x] Keyboard shortcuts, semantic buttons, live text, responsive layout and reduced-motion support.
- [x] Node built-in tests and GitHub Actions checks.
- [ ] Manual browser acceptance on desktop, phone, and Quest browser after merge.

## Companion episode: The Walbash Avenue Job (PR #1 addendum)

- [x] Larry, Tweedsie and Mavis character bible with complementary builder/explorer/equalizer roles and coherent limits.
- [x] Standalone, offline-playable StarChucks construction incident with character dialogue and four required actions.
- [x] Two outcomes, lasting magical cost, dedicated versioned local save, independent reset, keyboard/touch controls.
- [x] Tests for step ordering, invalid saves, replay protection and both endings.
- [ ] Manual smoke test on desktop, mobile and Quest browser after merge.
- [ ] Any cross-repository TweedleVerse bridge requires separate review and opt-in; do not imply it is implemented.

## Archive experiment: The First Stair (independent slice)

- [x] Independent four-room 2D browser journey: structure, dream, perspective, synthesis.
- [x] Meaningful puzzle gates, distinct endings and local-only save, separate from arrival and Walbash.
- [x] Original SVG artwork, keyboard-operable buttons and a journal with screen-reader feedback.
- [x] Automated state tests and GitHub Pages packaging.
- [ ] Manual browser verification on desktop, mobile and Quest browser.
- [x] Optional native-WebGL 3D stair annex: physical steps, first-person navigation and repeatable portal teleport.
- [x] Exit unlocked by witnessing the loop; independent checkpoint, input tests and fallback link.
- [ ] Manual desktop/mobile/Quest browser acceptance of WebGL view and controls.
- [ ] Seamless portal mask, multi-room 3D dream/perspective transitions, WebXR and comfort features are future work.

## Rung 1: The Crossroads proper
- Multi-room transit concourse and a first complete investigation chain.
- Character conversations with meaningful choices, not text dumps.
- Explain why different areas have different genre laws without resolving the core mystery.
- Keyboard, pointer, touch, reduced-motion and save migration tests.

## Rung 2: The Archive of Impossibilities
- A small set of original artifacts with history, anchor, cost, effect and containment rule.
- Retrieval mission, evidence-based identification, consequences and journal entries.
- Playtest for hard/soft locks and irreversible choices.

## Rung 3: Upper Management
- Departments, competing interests, a playable dispute and a case-file interface.
- Comic relief through bureaucratic incentives, while preserving human consequences.

## Rung 4: The First Door
- One fully realized realm with unique art, rules, companion(s) and a complete loop.
- Explicit opt-in bridge contract before any connection to other existing game repositories.

## Non-goals for first playable slice

No production multiplayer, backend, accounts, paid API dependency, real machine-learning model, external saves, asserted cross-game integration, or disclosure of another game's spoilers.

## Definition of done per rung

An offline-playable route, complete success/failure and recovery paths, explicit persistent-state schema, accessible controls, tests, and honest README status. Green CI is required before a merge is recommended.
